# Carpeta de Producción Digital 🎬

## ¿De qué trata mi proyecto?

Este proyecto nació de la idea de crear una herramienta que me permita organizar mejor mis proyectos audiovisuales, como una serie, un podcast o un cortometraje.

La idea es tener un espacio donde pueda registrar cada proyecto, consultar su información y llevar un seguimiento de la etapa en la que se encuentra.

## ¿Cómo funciona?

El programa permite:

- Registrar proyectos audiovisuales.
- Consultar su información.
- Modificar sus etapas y estados.
- Actualizar las fechas de entrega.
- Asociar programas como Audacity y DaVinci Resolve.

## ¿Qué aprendí?

Durante los avances fui construyendo y mejorando el proyecto. Aprendí a utilizar clases y objetos, herencia, polimorfismo, encapsulamiento, composición y modularización.

En esta última etapa organicé el código en dos archivos:

- `modelos.py`: contiene las clases.
- `main.py`: contiene la creación de objetos y las pruebas.
